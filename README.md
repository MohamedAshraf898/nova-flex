# Nova Flex — Fuel Station Systems

Landing page built from the Nova Flex Figma design with plain HTML, CSS and JavaScript, animated with GSAP and ScrollTrigger (loaded from cdnjs). No framework or build step.

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Files

- `index.html` — page markup
- `styles.css` — styles and responsive rules
- `main.js` — interactions and GSAP animations
- `assets/` — images and logos exported from Figma
